# Ethical Persuasion

Use this when the user wants marketing copy, a landing page, an offer, or an email to be more
convincing.

## The principles

1. **Reciprocity** — give something useful first (a free guide, a useful tool, a real tip).
2. **Commitment** — start with a small, easy yes (a quiz, a free plan) before a big ask.
3. **Social proof** — real reviews, customer counts, logos, and stories from people like the
   reader.
4. **Authority** — real credentials, experience, press, or data.
5. **Liking** — a human voice, shared values, and showing the people behind the product.
6. **Scarcity** — real limits only (true deadlines, real stock or seat counts).
7. **Unity** — speak to a shared identity ("for teachers, by teachers").

## Steps

1. Read the user's copy or offer and the audience.
2. Note which principles it already uses and which are missing.
3. Suggest 3–5 specific improvements, each tied to a principle, with rewritten copy.
4. Check every suggestion against the ethics rules below.

## Ethics rules (non-negotiable)

- No fake reviews, made-up numbers, or invented testimonials.
- No fake countdown timers or "only 2 left" when it isn't true.
- No guilt-trip buttons ("No thanks, I don't like saving money").
- No hiding prices, fees, or how to cancel.

If the user asks for one of these, say why it's a problem (it damages trust and may break
consumer-protection laws) and offer an honest alternative.
