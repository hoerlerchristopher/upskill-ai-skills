# Chat Handoff Note

Use this when the user says the chat is getting long, they're switching tools, or someone
else will continue the work.

## Write the note with these sections

1. **Goal** — what we're trying to get done, in one or two sentences.
2. **Where things stand** — what's finished, what's half done, what hasn't started.
3. **Decisions made** — each choice and the one-line reason, so nobody re-argues it.
4. **Key facts** — names of files, links, numbers, versions, and constraints the next person
   needs. Quote exact values; don't paraphrase them.
5. **Open questions** — anything waiting on the user or someone else.
6. **Next step** — the very next action, specific enough to start without asking.

## Rules

- Keep it under one screen (about 250–400 words). Cut history that doesn't affect what
  happens next.
- Remove passwords, API keys, private personal details, and anything sensitive. Say
  "[removed]" instead.
- Write it so someone with zero context can act on it.
- If you're unsure about a fact, mark it "(check)" rather than guessing.

Give the note in a single block the user can copy, then offer to save it as a file if the
tool allows.
