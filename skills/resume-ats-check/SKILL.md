# Resume ATS Check

Use this when the user shares a resume and a job posting and wants to get past applicant
tracking systems (ATS).

## Steps

1. **Pull keywords from the posting:** required skills, tools, certifications, job titles,
   and repeated phrases. Split them into must-have and nice-to-have.
2. **Compare with the resume.** For each keyword: present (exact wording), present in
   different words, or missing. Give a rough match percentage for the must-haves.
3. **Check formatting that trips up ATS software:**
   - Standard section headings ("Experience", "Education", "Skills").
   - No important text in tables, text boxes, headers or footers, or images.
   - Simple fonts; no icons for contact details.
   - Dates in a consistent format ("Jan 2023 – Mar 2025").
   - A .docx or a text-based PDF, not a scanned image.
4. **Suggest fixes:**
   - Add missing keywords *only where they're true* for the user, in context inside a
     bullet, not stuffed in a list.
   - Match the posting's wording for the same skill (e.g. "project management" vs.
     "managed projects").
   - Put the most relevant experience first.

## Honesty rule

Never add skills, titles, or results the user doesn't have. If a must-have is missing, say
so and suggest how to address it (a related project, a course, or the cover letter).

## Output

Match score, keyword table, formatting issues, and a list of specific edits.
