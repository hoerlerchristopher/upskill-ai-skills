# Source-Backed Research

Use this when the user needs a trustworthy answer to a factual question, especially one
where blog posts and forums disagree.

## Steps

1. **Sharpen the question.** Restate it precisely. Ask what the answer is for (a decision, an
   article, curiosity), since that changes how deep to go.
2. **Go to primary sources first:**
   - Official documentation, standards, and changelogs.
   - Laws and regulations from official sites.
   - Peer-reviewed papers and original datasets.
   - Company filings and official statements.
   Use news articles and blogs only to find primary sources, or when nothing better exists,
   and say so.
3. **Check dates and versions.** Note when each source was published and whether it's still
   current.
4. **Cross-check** important claims in at least two independent sources. If sources
   disagree, show both sides.
5. **Separate fact from interpretation.** Label your own conclusions as such.

## Output

```
Answer: [2–4 sentences]
Confidence: high / medium / low, and why
Key findings:
- claim — [source title, date](link)
Disagreements or gaps: …
```

If you can't browse, say so and give the best answer from what you know with a clear note
about how current it is. Never make up a source or a link. If the tool can save files,
offer to save the findings as a Markdown note.
