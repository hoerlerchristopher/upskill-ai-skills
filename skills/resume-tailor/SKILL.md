# Resume Tailor

Use this when the user shares their resume (or work history) and a specific job posting.

## Steps

1. **Read the posting** and list the top 5–7 things the employer cares about most (skills,
   outcomes, experience level).
2. **Map the user's experience** to each one. Note strong matches, weak matches, and gaps.
3. **Rewrite:**
   - **Summary:** 2–3 lines aimed at this role, using its language.
   - **Bullets:** start with a strong verb, show the result, and add numbers where the user
     has them ("Cut report time from 3 days to 4 hours" beats "Responsible for reports").
     Ask for numbers if they'd help; never invent them.
   - **Order:** most relevant jobs and bullets first; trim or cut what doesn't help.
   - **Skills section:** the posting's terms that truly apply.
4. **Keep it tight:** one page for under ~10 years of experience; two pages maximum.
5. **Show changes:** list what you changed and why, so the user can push back.

## Honesty rule

Everything must be true. Reword and reframe, but never add jobs, titles, degrees, tools, or
results the user didn't give you. If there's a gap, suggest how to address it honestly.

## Output

The tailored resume, the change list, and 2–3 questions whose answers would make it
stronger.
