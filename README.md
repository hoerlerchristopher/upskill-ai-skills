# Upskill AI skills

Free AI skills from [Upskill AI](https://upskillai.dev), a site where people post the skills they've
made and copy other people's into their own AI. Each skill is a short instruction file
(`SKILL.md`) that makes Claude, ChatGPT or Gemini better at one job.

## How to use one

- **Claude Code:** copy a folder from `skills/` into `~/.claude/skills/`.
- **Claude, ChatGPT or Gemini in the browser:** open the skill's page on upskillai.dev,
  click Copy, and follow the "How to add it" steps there.

Read a skill before you add it. A skill is instructions your AI will follow.
